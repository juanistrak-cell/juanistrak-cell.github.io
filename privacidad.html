Política de privacidad

Esta aplicación es una herramienta privada de uso exclusivo de su titular.

  • Solo accede a la cuenta de Google de la persona que la autoriza expresamente.
  • Los datos se procesan únicamente para el funcionamiento de la herramienta.
  • No vende, cede ni comparte datos con terceros.
  • No se usan datos para publicidad ni para entrenar modelos.
  • El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions.

El uso de la información recibida de las API de Google cumple con la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.
